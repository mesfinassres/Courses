Knowledge

The student...

is able to demonstrate knowledge of the key theories and concepts in information risk and security
is able to describe the main IT security frameworks, such as the ISO27000 series
is able to demonstrate knowledge and understanding of security risk analysis and assurance techniques
is able to demonstrate knowledge of main attack mechanisms and techniques
Skills

The student...

can conduct a systematic risk analysis, assessing probability and business impact
is able to design an IT security policy based on the risk analysis
can assess the quality of the security policy
General competence

The student...

can design and perform a risk analysis for an organization
is able to formulate and communicate an appropriate IT security policy, based on a IT security framework
is able to design and evaluate a security policy
